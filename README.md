# WF_myBank
My GCA submission - A responsive banking web application

## Features

- **Responsive Design**: Works on desktop and mobile devices
- **Transaction Management**: View transactions with category icons and edit functionality
- **Multi-month History**: Transaction data spans multiple months with month dividers
- **Account Balance**: Real-time balance calculation displayed prominently
- **Category-based Icons**: Visual icons for different transaction types (food, gas, shopping, etc.)
- **Edit Functionality**: Pencil icons for editing transactions
- **Navigation**: Clean navigation between Money and Budget sections

## Live Demo

This application is automatically deployed to GitHub Pages at: https://jobmckee.github.io/WF_myBank/

## Technologies Used

- HTML5
- CSS3 (with responsive design)
- Vanilla JavaScript
- Font Awesome icons
- GitHub Pages for deployment

## Local Development

1. Clone the repository
2. Open `index.html` in your browser
3. No build process required - it's a static web application
