## Banking Web Application

A modern, responsive banking web application that allows users to view and manage their transaction history.

### Features

- 📱 **Responsive Design**: Works seamlessly on desktop and mobile devices
- 💰 **Account Balance**: Real-time balance calculation displayed prominently
- 🏷️ **Category Tags**: Each transaction includes a category tag (food, gas, shop, etc.)
- 🔍 **Category Icons**: Visual icons based on transaction category
- ✏️ **Inline Editing**: Edit transaction titles with intuitive pencil icon
- 📅 **Monthly Grouping**: Transactions organized by month with clear dividers
- 🎯 **Clean UI**: Modern interface with improved navigation

### Live Demo

🚀 [View Live Application](https://jobmckee.github.io/WF_myBank/)

### Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Icons**: Font Awesome
- **Deployment**: GitHub Pages

### Local Development

1. Clone the repository
2. Open `index.html` in a web browser or serve with a local HTTP server
3. For development, you can use Python's built-in server:
   ```bash
   python3 -m http.server 8000
   ```
   Then visit `http://localhost:8000`
