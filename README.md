# WF_myBank
Personal Banking Web Application - GCA submission

## Features

✅ **Modern Banking Interface** - Clean, professional design with responsive layout  
✅ **Transaction Management** - View transactions with category icons and edit functionality  
✅ **Account Balance** - Bold, black text display of current balance  
✅ **Category System** - Visual icons for different transaction types (food 🍴, gas ⛽, shopping 🛍️, income 💵, entertainment 🎬)  
✅ **Month Grouping** - Transactions organized by month with clear dividers  
✅ **Mobile Responsive** - Optimized for both desktop and mobile devices  
✅ **GitHub Pages** - Live deployment ready  

## Navigation

- **Money** 💰 - View and manage transactions
- **Budget** 📊 - Budget overview (coming soon)

## Demo

The application is deployed and available at: [Live Demo](https://jobmckee.github.io/WF_myBank/)

## Local Development

To run locally:

```bash
# Clone the repository
git clone https://github.com/JobMcKee/WF_myBank.git
cd WF_myBank

# Start a local web server (Python 3)
python3 -m http.server 8080

# Or using Node.js
npx serve .

# Open http://localhost:8080 in your browser
```

## Architecture

- **Frontend**: Pure HTML5, CSS3, and JavaScript
- **Styling**: Responsive CSS with mobile-first approach
- **Icons**: Unicode emoji icons for better compatibility
- **Deployment**: GitHub Pages with automated workflow

## Requirements Implemented

1. ✅ Category tags at the bottom of each transaction
2. ✅ Pencil icons (✏️) on the right side of transaction items
3. ✅ Category-specific icons with color coding
4. ✅ Bold account balance display (always black text)
5. ✅ "Money" navigation instead of "Transactions"
6. ✅ 50% taller navigation items in desktop view
7. ✅ Multi-month transaction data with proper grouping
8. ✅ Organized transaction item layout
9. ✅ GitHub Pages deployment support
